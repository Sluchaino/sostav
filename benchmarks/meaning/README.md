# Сравнение правил и готовой модели

Изолированный эксперимент. Зависимости модели не добавлены в приложение, режим подбора пользователя не меняется.

- [Отчёт и все 63 проверочные фразы](REPORT.md).
- [90 фраз и ожидаемые предметы](cases.json): 27 calibration, 63 test, по 10 фраз в 9 категориях.
- [Описания предметов](objects.json): каталог из 10 предметов и карточка загруженной лестницы.
- [Полные результаты](results/comparison.json): оценки, выбранные предметы, косинусные рейтинги, калибровка, времена и контрольные суммы.

Разметка авторская, подготовлена агентом до запуска модели и правил. Она ещё не согласована с пользователем. Допустимые альтернативы и дополнения явно перечислены. Это рабочая оценка на небольшом предметном наборе; результат не характеризует все модели и все метафоры.

## Повторить

Нужен Node.js 22+ и интернет для первой загрузки пакетов и модели. Из корня проекта:

```powershell
npm ci
npm run build:core
npm ci --prefix benchmarks/meaning
node benchmarks/meaning/run.mjs
```

Модель `Xenova/paraphrase-multilingual-MiniLM-L12-v2` — ONNX-версия `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`. Зафиксирован revision `2c4055b12046f11709e9df2c122e59ffbdc2f900`, q8, CPU, mean pooling, нормализация. Runtime `@huggingface/transformers@3.8.1` зафиксирован отдельным package-lock. API-ключ не нужен. Скачиваются публичные веса и токенизатор (~129 МиБ); тексты фраз обрабатываются локально. Кеш `.cache/` и node_modules исключены из Git.

Первый запуск может занять время на скачивание. В опубликованном измерении модель заранее скачана и прогрета отдельным запуском; 1.56 с — загрузка из локального кеша, а не скачивание. Замеры Node CPU не следует считать замерами в браузере.

Скрипт пересчитывает отчёт и JSON результатов. Подбираются только порог абсолютного сходства, отрыв от первого кандидата и число выбранных предметов. Используются исключительно calibration-строки. Test-строки не участвуют в настройке. Настройки не менялись после просмотра итогов. Дополнительный гибрид использует excludedObjectIds текущих правил, а не запреты из эталона. Отдельный режим «правила, затем модель при отказе» не проверялся.

`metrics.mjs` содержит определения успеха, полноты, точности и калибровки. Корневые тесты проверяют метрики и пересчитывают опубликованные оценки без загрузки модели:

```powershell
node --test tests/meaning-benchmark.test.mjs
```

В CI модель не скачивается. Фразы calibration/test разделены вручную, некоторые тематически близки. Следующий набор для независимой проверки лучше составить пользователю после согласования эталона. Изменение эталона требует новой версии набора и нового отчёта; старые проценты не сохраняют силу автоматически.
