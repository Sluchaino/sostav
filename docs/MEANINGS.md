# Смыслы встроенных заготовок

Версия 0.9.0. Подбор использует 25 явных тем, словоформы, устойчивые сочетания и исключения. Это словарь визуальных связей, а не универсальное понимание языка. Новые теги также доступны в поиске библиотеки. SVG и их геометрия не менялись.

| Предмет | Расширенный контекст |
| --- | --- |
| Книга | Знания, опыт, практика, инструкция, руководство, память, воспоминания, исследование |
| Кошелёк | Оплата, личный бюджет, накопления денег, финансовая самостоятельность |
| Монета | Отдельная ценность, доход, цена, вознаграждение, заработок, вклад, обмен |
| Лампа | Идея, вдохновение, ясность, понимание, открытие, «пролить свет» |
| Пазлы | Решение из частей, взаимосвязь, сотрудничество, общее дело |
| Папка | Порядок, организация, систематизация, архив, подготовка |
| Телефон | Связь, общение, цифровые услуги, доступ, общение с клиентом |
| Ручка | Записи, выражение мыслей, планирование, авторство, договорённость, подпись |
| Наушники | Музыка, внимание, погружение, личное пространство, умение слушать, отдых |
| Ваза с цветами | Забота, уют, красота, благодарность, подарок, отношения, благополучие |

## Примеры подбора

Без включённых фоновых предметов:

| Фраза | Предметы |
| --- | --- |
| Инструкция по управлению бюджетом | Книга + кошелёк |
| Исследовать новую идею | Книга + лампа |
| Собрать накопленный опыт | Книга + пазлы |
| Услышать клиента | Наушники + телефон |
| Знания приносят доход | Книга + монета |
| Забота о себе | Цветы + наушники |
| Ценный вклад в общее дело | Монета + пазлы |
| Благодарность за помощь | Цветы |
| Пролить свет на сложный вопрос | Лампа |
| Подписать договор | Ручка |

Один смысл может передаваться несколькими предметами, а фраза — сочетать темы. Объяснения выбора показаны в «Изменить предметы», состав можно исправить вручную.

## Ограничения и защита от случайных совпадений

- «Бюджет», «накопления», «финансовая самостоятельность» выбирают кошелёк; «цена», «доход», «вознаграждение» — монету. Составной финансовый запрос может включать оба предмета.
- «Накопленный опыт» связан с книгой и не добавляет кошелёк по одному корню «накоп…».
- «Память поколений» связана с книгой. Технические слова рядом с памятью подавляют эту связь: «память телефона» оставляет телефон, «оперативная память компьютера» требует уточнения. Это консервативное правило: сложная смешанная фраза может потерять связь с воспоминаниями.
- «Вклад» распознаётся по перечисленным словоформам; «вкладка браузера» не превращается в монету. «Памятник» не превращается в книгу.
- Устойчивые сочетания не сопоставляются через границы предложений. Прежние исключения вроде «без книги» сохраняются.
- Правила не распознают все формы слов, иронию и произвольные переносные значения. Теги помогают поиску; автоматический подбор определяется связями и их весами в `src/editor/meaning.ts`.

## Проверка

В `tests/expanded-meaning.test.mjs` проверены новые сочетания, различение финансовых смыслов, отрицания, неоднозначные слова, поиск и работа с ограниченным каталогом. Для нового подбора проверены переносимые проекты и три расположения в обоих размерах и трёх форматах. Всего 70 автоматических тестов проходят.

Повторный проход только правил на прежних 63 test-фразах сравнения: 47 успешных, как прежде; ни одна ранее успешная фраза не стала ошибочной. Разметка и прежние результаты сохранены. Это проверка регрессий на знакомом авторском наборе, а не независимый замер улучшения качества и не новый эксперимент с моделью.
