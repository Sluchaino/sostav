# Сочетания и перефразировки, 0.11.0

Подбор работает в браузере без новых зависимостей, модели, API-ключей и сервера. Словарь сочетаний находится в `src/editor/phrases.ts`; темы и связи с предметами — в `src/editor/meaning.ts`.

## Что изменилось

Сначала сопоставляются сочетания слов. Их слова учитываются в распознанной теме и не запускают противоречащие общие правила. Остаток фразы продолжает обрабатываться как раньше: можно совместить несколько смыслов. Явные названия предметов и карточки своих SVG сохраняются.

| Формулировка | Смысл / результат без дополнительных фоновых предметов |
| --- | --- |
| Получать знания / получать новые полезные знания | Книга |
| Освоить новую профессию / повысить квалификацию | Книга |
| Зафиксировать мысли на бумаге / изложить свои мысли | Ручка |
| Собрать мысли | Ручка; «собрать» не добавляет пазлы |
| Открыть вклад | Кошелёк; «открыть» не добавляет телефон, «вклад» — монету |
| Работа над собой | Книга; «работа» не добавляет рабочие принадлежности |
| Руководство командой | Пазлы; «руководство» не добавляет книгу-инструкцию |
| Перезагрузить телефон | Телефон; «перезагрузить» не добавляет отдых |
| Привести дела в порядок / разложить по местам | Папка |
| Получить награду / получить отдачу / труд окупается | Монета |
| Выразить признательность / поднять настроение | Ваза с цветами |
| Оставаться на связи / наладить контакт | Телефон |
| Действовать сообща / плечом к плечу | Пазлы |
| Найти общий язык | Телефон + пазлы |
| Повысить квалификацию и получить награду | Книга + монета |
| Собрать мысли и увеличить доход | Ручка + монета |

При совпадении сочетания главный предмет его темы получает небольшой приоритет перед необязательными дополнениями. Объяснения содержат исходные слова пользователя в `interpretation.concepts[].evidence`; исходная фраза не переписывается.

## Границы

- Поддерживаются перечисленные в словаре префиксы форм слов, а не полная русская морфология. `*` означает явно разрешённый префикс; `/` — перечисление альтернатив.
- Между словами сочетания допускаются не более двух известных определений, например «новые», «полезные», «свои». Произвольные слова и союзы не пропускаются.
- Сочетания не проходят через границы предложений, запятые и разделы отрицания. «Получить; награду» не считается сочетанием «получить награду». Однословные правила при этом могут распознавать отдельные части текста независимо.
- Явные запреты применяются после распознавания смыслов. «Без денег» исключает и кошелёк, и монету; форма «денег» теперь распознаётся отдельно от «деньги».
- Это расширение явного словаря. Не поддерживаются все перефразировки, сложные отрицания, опечатки, ирония и произвольные метафоры. Неизвестную фразу можно уточнить, а предметы — исправить вручную.

## Проверка

Пять новых групп тестов в `tests/phrases.test.mjs`: формы и сочетания; приоритет смысла фразы; отрицания и границы; детерминированность, свои SVG и ограниченный каталог; сохранение нескольких смыслов через компоновку и JSON. Всего 83 автоматических теста проходят.

На прежних 63 test-фразах авторского benchmark: 49 успешных против 47 до изменения, без новых регрессий. Улучшились «Освоить новую профессию» и «Зафиксировать мысли на бумаге». Этот набор уже просматривался, результат является проверкой регрессий на знакомых фразах, а не независимой оценкой точности. Исторические модельные отчёты и исходная разметка не изменены.
