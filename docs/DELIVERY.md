# Демонстрация «Состава»

Описание проекта, архитектура, AI-инструменты и SVG-превью композиций собраны в [README](../README.md).

## Сценарий демонстрации

Фраза → выбор S/L → готовые варианты → ручная правка → смена палитры → проверка и SVG. Экспорт открывается в Figma с отдельными группами и контурами. Дополнительный сценарий — свой SVG с карточкой смыслов и независимыми цветовыми назначениями для главной и фоновой роли.
