# Видеообзор — пересъёмка, 2 минуты 52 секунды

[Смотреть новую версию MP4](demo-v2.mp4) · [Субтитры SRT](demo.srt)

Приложение и Figma пересняты в рабочей области **1600 × 1000**. Figma показывает весь экспорт с масштабом 86%, телефон — 265%, а отдельный контур приближен в режиме узлов. Участок Figma снят заново: вставлен новый скачанный SVG, изменены поворот и заливка внутреннего Vector. Page 1 не менялась; предыдущий тестовый Frame перемещён вправо, новый экспорт находится отдельной рамкой на странице проверки.

Перед каждым действием жёлтая рамка отмечает кнопку или поле. Видны движение указателя, красный импульс нажатия и результат. Для ввода выделяется соответствующее поле; для клавиатурных действий показана комбинация клавиш. Указатель и метки добавлены при монтаже по координатам реально использованных элементов интерфейса. Это пошаговый показ кадров до/после действий, без озвучки; непрерывной записью мыши его не выдаём.

На действие отведено пять секунд: сначала место нажатия, затем результат. Начальная карточка — семь секунд, финальная — пять. Видеокадр **1600 × 1160**, H.264, 24 кадра/с, 172 секунды. Субтитры встроены в изображение, SRT приложен отдельно.

## Таймкоды

- 00:00 — задача, запуск через npm.cmd, обозначение подсветки.
- 00:07 — Нажимаем «Собрать композицию» над холстом.
- 00:12 — Вводим фразу «Обучение через интернет».
- 00:17 — Выбираем S — компактную детализацию исходных SVG.
- 00:22 — Нажимаем «Построить композицию»: появляются три варианта.
- 00:27 — Применяем выбранный вариант кнопкой «Открыть в редакторе».
- 00:32 — Щёлкаем по телефону на холсте: справа открываются его параметры.
- 00:37 — В поле «Поворот» справа вводим 18°.
- 00:42 — Нажимаем бирюзовую схему: вся композиция перекрашивается.
- 00:47 — Кнопка «Скачать SVG» сначала открывает проверку композиции.
- 00:52 — Подтверждаем скачивание. Предметы сохраняются в SVG отдельными группами.
- 00:57 — В Figma вставляем содержимое скачанного SVG: Ctrl+V. Клавиши: `Ctrl+V`.
- 01:02 — Shift+2 крупно вписывает выбранную композицию в рабочую область. Клавиши: `Shift+2`.
- 01:07 — В слоях выбираем «Телефон». Shift+2 приближает сам предмет. Клавиши: `Shift+2`.
- 01:12 — В поле Rotation справа меняем угол на −10°.
- 01:17 — Enter раскрывает внутренний Frame выбранного предмета. Клавиши: `Enter`.
- 01:22 — Выбираем отдельный слой Vector внутри телефона.
- 01:27 — В поле цвета меняем заливку одного контура на FF6B6B.
- 01:32 — Enter открывает узлы, Shift+2 приближает выбранный контур. Клавиши: `Enter → Shift+2`.
- 01:37 — Новый сценарий: «Загрузить свои SVG» → выбираем ladder.svg.
- 01:42 — В поле «Смыслы и метафоры» задаём ассоциации своего SVG.
- 01:47 — В разделе «Цвета» назначаем первому цвету «Основной акцент предмета».
- 01:52 — Второму цвету назначаем «Дополнительный акцент предмета».
- 01:57 — Переключаемся на отдельную вкладку «Фоновый · монохромный».
- 02:02 — Прокручиваем ниже и нажимаем «Назначить монохром по яркости».
- 02:07 — Сохраняем обе независимые карты цветов.
- 02:12 — Прокручиваем библиотеку вниз и нажимаем карточку ladder.
- 02:17 — В поле X задаём 300: главная цветная копия находится слева.
- 02:22 — Нажимаем кнопку дублирования предмета в правой панели.
- 02:27 — Для дубликата нажимаем «Фоновый»: цвета переключаются на монохром.
- 02:32 — В поле X задаём 700: фоновая копия перемещается вправо.
- 02:37 — Переключаем палитру: обе копии перекрашиваются с учётом своих ролей.
- 02:42 — Кнопка «Проект» сохраняет JSON со своим SVG и обеими картами цветов.
- 02:47 — результаты и материалы проекта.

Сборка обзора: Pillow + FFmpeg через временный imageio-ffmpeg. Зависимости приложения не менялись. Параметры и координаты показанных действий сохранены в [storyboard](demo-storyboard.json).
