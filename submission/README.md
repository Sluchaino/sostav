# Примеры для проверки

Сначала запустите редактор по [основной инструкции](../README.md).

| Пример | Посмотреть вектор | Открыть и редактировать в сервисе |
| --- | --- | --- |
| Обучение через интернет — S, 1000 × 1000 | [learning.svg](examples/learning.svg) | [learning.sostav.json](examples/learning.sostav.json) |
| Безопасные покупки — L, 1200 × 630 | [finance.svg](examples/finance.svg) | [finance.sostav.json](examples/finance.sostav.json) |
| Свой SVG в главной и фоновой роли — L, 1200 × 630 | [custom-roles.svg](examples/custom-roles.svg) | [custom-roles.sostav.json](examples/custom-roles.sostav.json) |

Нажмите **«Открыть проект»** и выберите `.sostav.json`. Предметы и палитры восстановятся. В третьем проекте исходный SVG и обе карты цветов встроены в файл. Смените палитру — главная копия остаётся цветной, фоновая использует монохромные оттенки.

Для проверки импорта отдельно:

- [ladder.svg](examples/ladder.svg) → **«Загрузить свои SVG»**. Название «Лестница», теги «лестница, ступени», смыслы «рост, развитие, путь к успеху». В автосборке введите «Путь к успеху» и включите «Только мои SVG».
- [palette-forest.json](examples/palette-forest.json) → **«Загрузить палитру JSON»** справа. Палитра «Лесная» сразу перекрасит композицию.

SVG-файлы можно открыть в Figma; JSON предназначен для редактора «Состав». Все три SVG — векторные, без растровых вставок.
